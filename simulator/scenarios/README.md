# Forgatókönyv-katalógus

A 12 scenario a `simulator/SimulationRunner.cpp` `scenarios()` függvényében szerepel egyetlen, típusos definícióként. Ugyanezt futtatja a `test_scenarios` és a Windows EXE. A külön üres modellek és duplikált konfigurációs fájlok helyett ez biztosítja az egyezést.

CLI lista: `pinceszellozteto.exe --list`. A részletes elvárások a `docs/simulation.md` dokumentumban találhatók. A CSV-k generált kimenetek, nem forrásadatok.
